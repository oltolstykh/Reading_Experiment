Эксперимент по изучающему чтению – ссылки для групп

Студенты получают прямую ссылку на свою страницу, эту страницу им показывать не нужно.

ГруппаЗанятие 1Занятие 2 (через неделю)
Группа 1text1-a.html (текст 1, вариант А)text2-b.html (текст 2, вариант Б)
Группа 2text1-b.html (текст 1, вариант Б)text2-a.html (текст 2, вариант А)

Для проверки страниц без записи в основные данные добавьте к адресу ?test=1, например text1-a.html?test=1. Такие строки попадут в таблицу с пометкой test в столбце mode.
